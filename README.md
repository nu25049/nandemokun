# 暇な君へ

何をするか迷ったとき、本人が登録した行動候補から1件を提案するWebアプリ。

## 開発
`npm install` → `npm run dev` → http://localhost:3000

検証：`npm test`、`npm run typecheck`、`npm run build`。

自分の候補はlocalStorageに保存されます。画面内の計算・なぞなぞ、任意の天気・周辺のお店・Canvas連携に対応しています。Supabase・端末間同期は未接続です。

## 1分からの提案（2026-10-12）
- 初期の空き時間は1分。「おまかせ」で条件に合う候補から1件を選びます。1・3・5・10・15・30・60分、時間指定なしに対応し、種類でも絞れます。
- ホームは最上部に提案ボタン、その下の左にオプション、右に暇つぶしの入口を配置します。スマートフォンでは縦に並びます。
- 計算・なぞなぞは専用の `/play` 画面で大きく表示。移動操作は戻るだけで、計算は正解を入力すると即座に次の問題へ進みます。なぞなぞは3択に答え、解説を5秒表示したあと自動で次へ進みます。
- 開始前にカウントダウン（1・3・5・10・15・30・60分）またはカウントアップ（戻るまで継続）を選べます。提案経由の遊びは空き時間内で最大10分、右の入口では指定した時間で遊べます。時計は実時間から計算し、画面を離れている間も進みます。
- お店は検索ボタンを押したときだけ現在地を取得し、OpenStreetMap/Overpassで周囲800mを検索します。徒歩の往復と滞在15分が時間内に収まる店を提案します。徒歩時間は直線距離からの概算で、営業中かは確認していません。検索は30秒間隔、結果は15分で解除します。
- Canvasは利用者指定の `https://nu.instructure.com` に固定し、`GET /api/v1/users/self/todo` を最大3ページ取得します。未提出の課題・小テストを期限順に表示し、短時間の確認・着手として提案します。ToDo APIの範囲であり全コースの全課題を網羅するものではありません。
- Canvasトークンは画面の入力欄にのみ入力してください。トークン・課題・位置・お店の結果は永続保存せず、課題とお店は15分で提案から解除します。トークンと課題は再読み込み・解除でも消えます。読み取り専用の処理で、提出・課題の変更は行いません。
- 外部連携の未設定・拒否・失敗時も画面内の遊びは利用できます。自分の候補をすべて削除しても遊べる一方、「自分の候補」だけを選んだ場合の0件では提案を停止します。

実装・検証・本番反映の最新結果は `制作内容/共有メモ.md` を参照してください。本人のCanvasトークンによる実接続と現在地での評価は別途必要です。

## 天気と場所の条件（2026-10-09）
- 「室内だけにする」は位置情報なしでも利用できます。使える時間の条件と組み合わせて候補を絞ります。
- 「現在地の天気に合わせる」を押すと位置情報の許可を求め、概略座標（小数点以下2桁）をOpen-Meteoへ送信します。位置情報・天気は保存しません。
- 雨・雪・雷雨・霧のときは室内候補に限定します。晴れ・くもりのときは場所を制限しません。モデルによる現在天気の推定で、外出の安全を判定する機能ではありません。
- 位置情報の拒否、通信失敗、不正・古い応答では場所条件を解除し、時間条件を保った通常提案に戻ります。通信には8秒、位置取得には10秒のタイムアウトを設定しています。
- 条件に合う候補が0件なら提案を止め、条件変更や追加を案内します。候補一覧は削除しません。場所条件と天気情報は再読み込みでリセットされます。
- 天気データは90分を超えると解除されます。提供元：[Open-Meteo](https://open-meteo.com/)（[API仕様](https://open-meteo.com/en/docs)）。

最新の短い仕様報告は `制作内容/現在の仕様報告書.md` を参照してください。

## 第二回の追加機能
- 使える時間（指定なし / 5・15・30・60分以内）に合う候補から1件を提案します。対象0件なら時間条件の解除を案内します。
- 「同じ候補の連続を避ける」を有効にすると、別の対象候補がある場合は直前と違う候補を提案します。対象1件なら同じ候補を提案できます。

上記は第2回当時の仕様です。現在の初期時間は1分・連続回避なしで、設定は再読み込みで初期状態に戻り、登録した候補は保持されます。提出用の記録は `制作内容/第2回週次進捗報告.md`。
