# 「暇な君へ」でGoogleログインを使う

Supabaseでログインと好みの保存を管理し、Googleアカウントで本人を確認します。初回のGoogleログインが登録を兼ねます。Googleログインだけで始める場合、メール送信の設定は後回しにできます。

## 1. Supabaseで保存先を作る

1. [Supabase Dashboard](https://supabase.com/dashboard)にログインし、**New project** でこのアプリ用のプロジェクトを作ります。組織がなければ先に作成します。プロジェクトのデータベース用パスワードは手元で保管します。
2. プロジェクトの **SQL Editor → New query** を開きます。[supabase/preferences.sql](../supabase/preferences.sql) の内容をすべて貼り付けて、**Run** を1回実行します。`recommendation_preferences` テーブルと、ログインした本人だけが自分の設定を読み書きできる行単位の制限を作ります。
3. プロジェクトの **Connect** から **Project URL** と **Publishable key** を控えます。キーは **Settings → API Keys** からも確認できます。後ほどVercelに入力します。
4. **Authentication → URL Configuration** で、**Site URL** に `https://softwearcreationwhatdo.vercel.app`、**Redirect URLs** に `https://softwearcreationwhatdo.vercel.app/auth/confirm` を設定します。

[SupabaseのAPIキー](https://supabase.com/docs/guides/getting-started/api-keys)・[SupabaseのリダイレクトURL](https://supabase.com/docs/guides/auth/redirect-urls)

## 2. Google CloudでOAuthクライアントを作る

1. [Google Cloudコンソール](https://console.cloud.google.com/)でプロジェクト選択を開き、**新しいプロジェクト** を作ります。作成したプロジェクトを選んで [Google Auth Platform](https://console.cloud.google.com/auth/overview) を開き、**Get started** からアプリ名「暇な君へ」、サポート用メール、連絡先を設定します。個人のGoogleアカウントで使う場合は **Audience** で **External（外部）** を選びます。テストユーザーの指定を求められたら、自分のGoogleアカウントを追加します。
2. **Data Access** で `openid`、`userinfo.email`、`userinfo.profile` を確認し、不足分を追加します。
3. **Clients → Create client** を開き、種類を **Web application（ウェブ アプリケーション）** にします。**承認済みのJavaScript生成元** に `https://softwearcreationwhatdo.vercel.app` を入力します。**承認済みのリダイレクトURI** には、Supabaseの **Authentication → Sign In / Providers → Google** に表示される **Callback URL** をコピーして入力します。
4. 作成後に表示される **Client ID** と **Client secret** を控えます。シークレットは次の手順でSupabaseのGoogle設定に入力します。

認証の戻り先は2か所あります。

| 入力先 | 入力するURL |
| --- | --- |
| Google Cloudの承認済みリダイレクトURI | `https://<project-ref>.supabase.co/auth/v1/callback`（SupabaseのGoogle設定画面からコピー） |
| SupabaseのRedirect URLs | `https://softwearcreationwhatdo.vercel.app/auth/confirm`（このアプリの確認ページ） |

GoogleからSupabaseへ戻り、Supabaseからアプリへ戻る順番です。Google CloudにはSupabase側のURLを登録します。

[GoogleのOAuthクライアント設定](https://support.google.com/cloud/answer/15549257?hl=ja)・[SupabaseのGoogle設定](https://supabase.com/docs/guides/auth/social-sign-in/auth-google)

## 3. SupabaseでGoogle登録を有効にする

**Authentication → Sign In / Providers → Google** を開き、Googleを有効にします。Google Cloudで作った **Client ID** と **Client secret** を入力して保存します。**Allow new users to sign up** も有効にします。これで初めてのGoogleログイン時にアカウントを作成できます。

[Supabaseの登録設定](https://supabase.com/docs/guides/auth/general-configuration)

## 4. Vercelへ接続し、再配備する

[Vercel Dashboard](https://vercel.com/dashboard)で「暇な君へ」を配信しているプロジェクトを開き、**Environment Variables** に次の3つを追加します。各項目で **Production** を選びます。

| 名前 | 値 |
| --- | --- |
| `SUPABASE_URL` | SupabaseのProject URL（`https://<project-ref>.supabase.co`） |
| `SUPABASE_PUBLISHABLE_KEY` | SupabaseのPublishable key（`sb_publishable_…`） |
| `SUPABASE_GOOGLE_ENABLED` | `true` |

GoogleのClient secretはSupabaseにだけ入力します。Vercelには上の3項目を入力し、`sb_secret_…` や `service_role` キーは使いません。実際のキーやパスワードをGitやチャットに貼らないでください。

保存したら **Deployments** から最新の本番配備を選び、メニューの **Redeploy** を実行します。設定の変更は新しい配備から適用されます。

[Vercelの環境変数設定と再配備](https://vercel.com/docs/environment-variables/managing-environment-variables)

## 5. 接続後に確認する

1. [公開サイトの「好み・ログイン」](https://softwearcreationwhatdo.vercel.app/#preferences) を開き、**Google で登録・ログイン** を押します。Googleでアカウントを選んだ後、公開サイトに戻って「ログイン中」と表示され、Supabaseの **Authentication → Users** に登録されたことを確認します。
2. 提案の好みを1つ変更して **この好みをアカウントに保存** を押します。ログアウトして同じGoogleアカウントで入り直し、設定が復元されることを確認します。別のブラウザーでも試すと、アカウントから復元できたことを確認できます。
3. 別のGoogleアカウントでも試せる場合は、1人目の好みが表示されず、それぞれの設定が保存されることを確認します。ログアウト後はゲストの端末内設定に戻り、提案やゲームを利用できます。

Google側で `redirect_uri_mismatch` が出たら、手順2で設定したSupabaseのCallback URLを見直します。Googleでの操作後にアプリへ戻れなければ、手順1のRedirect URLsを見直します。ボタンが準備中のままなら、手順4のProductionの設定と再配備を確認します。

アカウントに保存できるのは提案の好みです。自作候補や利用記録はブラウザーに保存されます。実際の登録・保存・復元は、上記を接続してから確認します。

## ローカルやメールリンクも使う場合

- ローカルでも試す場合は、`.env.example` を参考に `.env.local` に同じ3項目を設定します。Supabaseの **Redirect URLs** に `http://localhost:3000/auth/confirm` を追加します。ローカルのGoogle設定を追加する場合は **承認済みのJavaScript生成元** に `http://localhost:3000` を追加し、同じSupabaseプロジェクトを使う間はGoogle側のCallback URLも同じです。
- メールリンクも提供する場合は、Supabaseでメール認証と送信設定を確認します。リンクは発行したブラウザーで開きます。[Supabaseのメール送信設定](https://supabase.com/docs/guides/auth/auth-smtp)
